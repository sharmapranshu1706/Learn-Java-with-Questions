# Learn Java with Questions

A hands-on repository for learning core Java concepts through code examples and practice questions. Each topic is paired with problems to reinforce understanding — from language fundamentals to data structures and algorithms.

## About

This repo tracks my Java learning journey with a focus on building a strong foundation for full-stack development. It combines concept notes, working code, and solved problems.

## Topics Covered

### Core Java
- Access modifiers (`public`, `private`, `protected`, default)
- Inheritance and polymorphism
- Classes, objects, and encapsulation

### Memory Management
- Stack vs. Heap memory
- Object lifecycle and garbage collection

### Data Structures & Algorithms
- Arrays and array manipulation
- Kadane's Algorithm (maximum subarray)
- Prefix Sum techniques
- Problem-solving patterns

## Getting Started

### Prerequisites
- Java JDK 17 or higher
- IntelliJ IDEA (recommended)
- Maven

### Running the Code

Clone the repository:
```bash
git clone https://github.com/<your-username>/Learn-Java-with-Questions.git
cd Learn-Java-with-Questions
```

Compile and run a specific file:
```bash
javac src/algorithms/MaxSubArrayIII.java
java MaxSubArrayIII
```

Or open the project in IntelliJ IDEA and run individual classes directly.

## How to Use This Repo

1. Pick a topic from the list above.
2. Read through the example code to understand the concept.
3. Attempt the practice questions before checking the solutions.
4. Experiment by modifying the examples.
